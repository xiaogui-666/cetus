# Cetus · 鲸屿

**不登录，不注册。带上你自己的 Key，跟任意一个愿意接你的模型聊。**

一个轻量的 AI 客户端 —— 没有账号体系，没有中间服务器，没有数据上云。
你的会话留在你自己的浏览器里，你的 Key 也只在你自己的设备上。

</div>

---

## 为什么做这个

官方网页版很好用，但它是给所有人用的：要登录、数据在云端、历史不能带走、参数不能调、只能用一家的模型。

鲸屿想解决的是另一小撮人的需求 —— **那些想自己管 Key、自己管数据、不想被账号和单一厂商绑住的人**。

所以这里没有：

- ❌ 注册 / 登录 / 手机验证
- ❌ 用户画像 / 埋点 / 统计
- ❌ 中间服务器转发（请求从你的浏览器直接打到供应商）
- ❌ 云端会话存储

只有：

- ✅ 一个输入框，和它该有的一切

## 功能

| | |
|---|---|
| **对话** | 流式输出、可随时停止、继续生成、编辑提问、重新生成、消息分支切换 |
| **模型** | 会话级模型选择；每个会话用哪个模型互不影响；新对话继承全局默认 |
| **思考** | 深度思考开关与强度（关闭 / 轻度 / 中等 / 高），滑块吸附档位 |
| **供应商** | 自定义地址与 Key，支持 **OpenAI / Anthropic 双协议**，模型列表自动拉取，可改显示名、类别、多模态与思考能力 |
| **联网** | 智能搜索、链接自动阅读、来源引用标注（仅 Anthropic 协议） |
| **文件** | PDF / Office / 图片上传、粘贴、拖拽（仅 Anthropic 协议） |
| **语音** | 语音输入（带实时频谱）、回答朗读（仅 Anthropic 协议） |
| **渲染** | Markdown、代码高亮、KaTeX 公式、Mermaid 图表 |
| **数据** | 多会话、自动标题、重命名删除、历史 ZIP 导入导出 |
| **界面** | 浅色/深色主题、移动端布局、首次引导、简体中文/英文 |

## 上手

### 在线使用

打开 [https://xiaogui-666.github.io/cetus/](https://xiaogui-666.github.io/cetus/) ，进入**设置 → 供应商**填入地址与 Key，拉取模型即可开聊。

手机上可以用浏览器菜单里的「添加到主屏幕」，它会以全屏应用的样子运行。

### 本地运行

需要 Node.js 22.12+ 与 pnpm：

```sh
pnpm install
pnpm dev
```

打开 http://localhost:8090 。

### 构建静态产物

```sh
pnpm build
```

产物在 `dist/`，可丢到任意静态服务器，也可以双击 `dist/index.html` 离线用（需浏览器允许 `file://` 页面访问存储与跨域请求）。

## 供应商与协议

在设置 → 供应商里添加，一个供应商 = 一套地址 + Key + 模型清单。

| 协议 | 端点 | 支持 |
|---|---|---|
| **Anthropic Messages** | `{地址}/anthropic/v1/messages` | 对话、思考、联网搜索、文件、语音、自动标题 |
| **OpenAI Chat Completions** | `{地址}/v1/chat/completions` | 对话、思考（服务返回 `reasoning_content` 时） |

> **关于 Anthropic 端点**：这里用的是 DeepSeek 的路径约定（`/anthropic/v1`），不是 `api.anthropic.com` 官方的 `/v1/messages`。
> 想接 Anthropic 官方或遵循官方路径的中转，目前要靠转发层适配。

> **关于跨域（CORS）**：请求是浏览器直连供应商的，对方必须允许跨域，否则会一直报网络异常。
> 关掉这个限制只能靠转发（自建 Worker 代理）或跑在桌面客户端里。
> DeepSeek 官方端点已允许跨域，第三方中转不一定。

OpenAI 协议的已知限制：不支持联网搜索 / 文件 / 自动标题，原因是这几项依赖 Anthropic 那边的服务端工具与 `title` 参数，OpenAI 协议里没有对应物。

## 数据与隐私

- **设置与供应商配置**：保存在浏览器 `localStorage`（含 Key 明文，设备和浏览器隔离）
- **会话与附件原件**：保存在浏览器 `IndexedDB`
- **网络行为**：只在发送对话、上传附件、使用语音时，把相应内容提交给你配置的供应商；除此之外没有任何外部请求
- **导入导出**：ZIP 格式，包含会话与本地图片原件，**不包含 Key 与设置**

> 清空浏览器数据 = 数据没了。重要会话请定期导出。

## 技术栈

React 18 · TypeScript · rspack · zustand · IndexedDB (idb) · 纯 CSS Modules + CSS 变量

协议层是「翻译」结构：Anthropic Messages 与 OpenAI Chat Completions 各自实现一个流式适配器，
都翻译成同一套内部事件流，所以上层的流合并、分支、持久化、渲染完全不感知协议差异。
